# 🐱 xiaoxie-live — AI 情绪引擎

> 为 AI Agent 构建的实时情绪状态系统，让 AI 拥有拟人化的情绪感知与表情展示能力。

基于 [OpenClaw](https://github.com/openclaw/openclaw) AI 管家系统设计，通过统一的行为驱动情绪模型，实现 AI 的情绪状态管理、表情切换和前端实时展示。

## 当前特点

- 全中文界面与文案
- 保持现有前端兼容,不大改视觉层
- 情绪判断集中在统一引擎,不再散落在多个脚本里
- 真实行为优先,但待机态会自然落在 `待机中 / 调皮中 / 困困的`
- 手动注入仍是最高优先级
- `data/状态.json` 与 `/api/status` 保持一致

## 支持的情绪

- `待机中`
- `思考中`
- `执行中`
- `开心中`
- `调皮中`
- `困困的`
- `惊讶中`
- `需注意`

## 关键文件

- `server.py`:本地静态服务与状态接口
- `run.sh`:启动脚本
- `live_status_sync.py`:实时同步循环,只负责调度引擎与写状态
- `pet_emotion_engine.py`:陪伴型宠物情绪引擎核心
- `status_store.py`:状态文件、兼容文件、手动注入的统一存储层
- `set_mood.py`:手动注入情绪
- `use_preset.py`:按预设快速注入情绪
- `mood_presets.json`:常用预设
- `PET_EMOTION_ENGINE.md`:完整设计文档
- `web/app.js`:前端轮询与表情切换
- `web/styles.css`:前端样式与动画

## 情绪引擎架构

当前自动判断分为五层:

1. 手动覆盖层
2. 真实行为层
3. 会话氛围层
4. 时间 / 节律层
5. 最终融合与防抖层

核心原则:

- 真在工具处理中时,用 `执行中`
- 用户消息待回复时,用 `思考中`
- 工具刚结束时,先过渡到 `思考中`
- 空闲时更多在 `待机中 / 调皮中 / 困困的` 之间变化
- `开心中` 只在明显轻松、收尾、正向互动时出现
- 深夜和疲惫语境会抬升 `困困的`

更完整设计见 `PET_EMOTION_ENGINE.md`。

## 启动方式

```bash
chmod +x run.sh
./run.sh
```

默认地址:

```bash
http://127.0.0.1:8876
```

## 直接运行

```bash
python3 live_status_sync.py
python3 server.py --host 0.0.0.0 --port 8876 --关闭模拟轮播
```

## 状态接口

浏览器默认每 `1.2` 秒轮询一次:

```bash
http://127.0.0.1:8876/api/status
```

状态字段保持兼容:

```json
{
  "情绪": "待机中",
  "标题": "待机中",
  "文案": "我在这里安静待机,等你下一句的时候再马上靠过来。",
  "更新时间": "2026-03-07 02:00:00",
  "轮播序号": 12,
  "来源": "自动判断"
}
```

另外会同步生成兼容文件 `data/status.json`:

```json
{
  "mood": "待机中",
  "title": "待机中",
  "message": "我在这里安静待机,等你下一句的时候再马上靠过来。",
  "updated_at": "2026-03-07 02:00:00",
  "cycle_index": 12,
  "source": "自动判断"
}
```

## 手动注入情绪

手动注入优先级最高,会直接覆盖自动判断:

```bash
python3 set_mood.py 思考中 "我在顺着你的意思认真想一想。" --持续秒数 15
python3 set_mood.py 执行中 "我正在把这几步动作连起来。" --持续秒数 20
python3 set_mood.py 调皮中 "我先眨眨眼,在这里陪你等下一句。" --持续秒数 25
python3 set_mood.py 困困的 "现在有点晚啦,我慢一点点但还陪着你。" --持续秒数 30
python3 set_mood.py 待机中 "我已经在线,在这里安静等你。" --持续秒数 20
```

常驻注入:

```bash
python3 set_mood.py 待机中 "我会一直在这里,直到你把我换掉。" --常驻
```

## 使用预设

```bash
python3 use_preset.py --列出
python3 use_preset.py 回答问题
python3 use_preset.py 调工具
python3 use_preset.py 完成收尾
```

## 情绪注入文件

`data/情绪注入.json` 格式:

```json
{
  "情绪": "开心中",
  "文案": "这一段已经落稳了,我带着好心情等你下一句。",
  "截止时间": 1779999999
}
```

说明:
- `截止时间 = 0` 表示常驻
- 超过截止时间后,自动判断会重新接管

## 设计与维护建议

- 想改算法时,优先修改 `pet_emotion_engine.py`
- 想改状态读写或兼容结构时,优先修改 `status_store.py`
- 想理解整体策略时,先看 `PET_EMOTION_ENGINE.md`
